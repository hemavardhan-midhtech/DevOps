# S3 (Simple Storage Service)

## What is Amazon S3?

Amazon S3 is AWS's object storage service used to store and retrieve unlimited amounts of data from anywhere.

Common Use Cases:

* Static Website Hosting
* Backups
* Log Storage
* Media Files
* Data Lakes
* Application Assets

---

# S3 Architecture

Application
↓
S3 Bucket
↓
Objects (Files)

Example:

my-company-bucket

├── images/
├── videos/
├── logs/
└── backups/

---

# Core Components

## Bucket

Container that stores objects.

Example:

devops-learning-bucket

Bucket names must be globally unique.

---

## Object

Files stored inside buckets.

Example:

resume.pdf

image.png

backup.tar.gz

---

## Object Metadata

Information about objects.

Examples:

* File Size
* Content Type
* Last Modified

---

# Storage Classes

## S3 Standard

Frequently accessed data.

High availability and durability.

---

## S3 Intelligent-Tiering

Automatically moves data based on access patterns.

---

## S3 Standard-IA

Infrequent Access.

Lower cost.

---

## Glacier Instant Retrieval

Archival storage.

---

## Glacier Flexible Retrieval

Long-term backups.

---

## Glacier Deep Archive

Lowest storage cost.

Used for compliance and archival.

# Versioning

Stores multiple versions of an object.

Benefits:

* Accidental deletion recovery
* Rollback capability

Enable:

Bucket → Properties → Versioning

---

# Lifecycle Rules

Automates storage transitions.

Example:

Day 30 → Standard IA

Day 90 → Glacier

Day 365 → Delete

# AWS CLI Commands

Create Bucket:

```bash
aws s3 mb s3://my-devops-bucket
```

List Buckets:

```bash
aws s3 ls
```

Upload File:

```bash
aws s3 cp app.zip s3://my-devops-bucket
```

Download File:

```bash
aws s3 cp s3://my-devops-bucket/app.zip .
```

Sync Directory:

```bash
aws s3 sync . s3://my-devops-bucket
```

Delete Object:

```bash
aws s3 rm s3://my-devops-bucket/app.zip
```
